# DataBOFconstants
{: .no_toc }

Action values for the **BOFAction** property of a Data control, controlling what happens when the user moves past the start of a recordset.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbMoveFirst**{: #vbMoveFirst } | 0 | Move back to the first record. |
| **vbBOF**{: #vbBOF } | 1 | The recordset is positioned at the beginning-of-file marker; navigation past it is disallowed. |
