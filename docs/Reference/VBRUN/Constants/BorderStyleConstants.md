# BorderStyleConstants
{: .no_toc }

Line-style values for the **BorderStyle** property of **Shape** and **Line** controls.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbTransparent**{: #vbTransparent } | 0 | No border is drawn. |
| **vbBSSolid**{: #vbBSSolid } | 1 | A solid border. |
| **vbBSDash**{: #vbBSDash } | 2 | A dashed border. |
| **vbBSDot**{: #vbBSDot } | 3 | A dotted border. |
| **vbBSDashDot**{: #vbBSDashDot } | 4 | A dash-dot border. |
| **vbBSDashDotDot**{: #vbBSDashDotDot } | 5 | A dash-dot-dot border. |
| **vbBSInsideSolid**{: #vbBSInsideSolid } | 6 | A solid border drawn entirely within the shape's bounds. |
