# DatabaseTypeConstants
{: .no_toc }

Engine values for the **DefaultType** property of a Data control, choosing which database back-end the control should use.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbUseODBC**{: #vbUseODBC } | 1 | Connect through ODBC. |
| **vbUseJet**{: #vbUseJet } | 2 | Connect through the Jet (Access) engine. |
| **vbUseACE**{: #vbUseACE } | 3 | Connect through the ACE (Access 2007+) engine. *(twinBASIC addition.)* |
