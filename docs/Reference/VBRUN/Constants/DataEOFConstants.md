# DataEOFConstants
{: .no_toc }

Action values for the **EOFAction** property of a Data control, controlling what happens when the user moves past the end of a recordset.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbMoveLast**{: #vbMoveLast } | 0 | Move forward to the last record. |
| **vbEOF**{: #vbEOF } | 1 | The recordset is positioned at the end-of-file marker; navigation past it is disallowed. |
| **vbAddNew**{: #vbAddNew } | 2 | A new record is automatically added so the user can continue past the last existing row. |
