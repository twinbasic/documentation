# LogEventTypeConstants
{: .no_toc }

Severity values for the *EventType* argument of the **LogEvent** method.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbLogEventTypeError**{: #vbLogEventTypeError } | 1 | The entry describes an error. |
| **vbLogEventTypeWarning**{: #vbLogEventTypeWarning } | 2 | The entry describes a warning. |
| **vbLogEventTypeInformation**{: #vbLogEventTypeInformation } | 4 | The entry is informational. |
