# DataErrorConstants
{: .no_toc }

Response values returned from a Data control's **Error** event handler.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbDataErrContinue**{: #vbDataErrContinue } | 0 | Continue execution as though no error had occurred. |
| **vbDataErrDisplay**{: #vbDataErrDisplay } | 1 | Display the standard error dialog and let the runtime handle the error. |
