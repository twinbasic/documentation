# ParentControlsType
{: .no_toc }

Wrapping mode for the [**ParentControls**](../ParentControls) collection, controlling whether each item is returned wrapped in its host **Extender** or as the bare control.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbNoExtender**{: #vbNoExtender } | 0 | Items are returned as the bare control, without the host's **Extender** wrapper. |
| **vbExtender**{: #vbExtender } | 1 | Items are returned wrapped in the host's **Extender**, exposing the container-supplied layout properties. This is the default. |
