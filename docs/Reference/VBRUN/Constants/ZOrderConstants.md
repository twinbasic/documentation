# ZOrderConstants
{: .no_toc }

Position selectors for the **ZOrder** method of forms and controls.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbBringToFront**{: #vbBringToFront } | 0 | Move the object to the front of its z-order so it is drawn on top of its siblings. |
| **vbSendToBack**{: #vbSendToBack } | 1 | Move the object to the back of its z-order so its siblings are drawn on top of it. |
