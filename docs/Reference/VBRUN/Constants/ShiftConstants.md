# ShiftConstants
{: .no_toc }

Bit flags for the *Shift* argument of mouse and key events, identifying which modifier keys are pressed. Combine with `Or` to test for multiple modifiers.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbShiftMask**{: #vbShiftMask } | 1 | **Shift** is held down. |
| **vbCtrlMask**{: #vbCtrlMask } | 2 | **Ctrl** is held down. |
| **vbAltMask**{: #vbAltMask } | 4 | **Alt** is held down. |
