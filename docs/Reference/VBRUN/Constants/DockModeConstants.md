# DockModeConstants
{: .no_toc }

Dock-edge values for forms and toolbars that can be docked against a side of their container.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbDockNone**{: #vbDockNone } | 0 | The window is not docked. |
| **vbDockLeft**{: #vbDockLeft } | 1 | The window is docked against the left edge of the container. |
| **vbDockTop**{: #vbDockTop } | 2 | The window is docked against the top edge. |
| **vbDockRight**{: #vbDockRight } | 3 | The window is docked against the right edge. |
| **vbDockBottom**{: #vbDockBottom } | 4 | The window is docked against the bottom edge. |
| **vbDockFill**{: #vbDockFill } | 5 | The window fills the entire container area. |
