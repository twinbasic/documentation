# AlignmentConstants
{: .no_toc }

Text alignment values for the **Alignment** property of label, text box, and option button controls.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbLeftJustify**{: #vbLeftJustify } | 0 | Text is left-justified. |
| **vbRightJustify**{: #vbRightJustify } | 1 | Text is right-justified. |
| **vbCenter**{: #vbCenter } | 2 | Text is centred. |
