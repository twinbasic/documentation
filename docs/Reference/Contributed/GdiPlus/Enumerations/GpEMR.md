# GpEMR enumeration
{: .no_toc }

Gives the numbers of the record types of an enhanced metafile (EMF), the **EMR_** constants of the Windows header files.

Each record of an enhanced metafile begins with one of these numbers. Most records store one GDI call, and the name of the member says which: **EMR_POLYGON** stores a **Polygon** call. Members from **EMR_SETICMMODE** on exist from Windows 95 and Windows NT 4.0, and from **EMR_RESERVED_105** on from Windows 2000. Several numbers are reserved or not used. **EMR_MIN** and **EMR_MAX** are the lowest and the highest valid numbers. [GpEmfPlusRecordType](GpEmfPlusRecordType) repeats these numbers as its **EmfRecordType** members.
