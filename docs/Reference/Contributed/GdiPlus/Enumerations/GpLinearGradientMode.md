# GpLinearGradientMode enumeration
{: .no_toc }

Selects the direction in which the colour of a linear gradient brush changes.

| Member | Value | Description |
|:-------|:------|:------------|
| **LinearGradientModeHorizontal**{: #LinearGradientModeHorizontal } | `0` | The colour changes from left to right. |
| **LinearGradientModeVertical**{: #LinearGradientModeVertical } | `1` | The colour changes from top to bottom. |
| **LinearGradientModeForwardDiagonal**{: #LinearGradientModeForwardDiagonal } | `2` | The colour changes from the upper left corner to the lower right corner. |
| **LinearGradientModeBackwardDiagonal**{: #LinearGradientModeBackwardDiagonal } | `3` | The colour changes from the upper right corner to the lower left corner. |
