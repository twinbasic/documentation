# GpPenAlignment enumeration
{: .no_toc }

Selects the position of a pen relative to the line it draws.

| Member | Value | Description |
|:-------|:------|:------------|
| **PenAlignmentCenter**{: #PenAlignmentCenter } | `0` | The pen is centred on the line, half of its width on each side. |
| **PenAlignmentInset**{: #PenAlignmentInset } | `1` | The pen is on the inside of the line. For a closed shape the whole width is inside the shape. |
