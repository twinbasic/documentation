# GpBrushType enumeration
{: .no_toc }

Names the kind of fill that a brush produces.

| Member | Value | Description |
|:-------|:------|:------------|
| **BrushTypeSolidColor**{: #BrushTypeSolidColor } | `0` | A solid colour fill. |
| **BrushTypeHatchFill**{: #BrushTypeHatchFill } | `1` | A hatch fill. |
| **BrushTypeTextureFill**{: #BrushTypeTextureFill } | `2` | A fill made of tiles of an image. |
| **BrushTypePathGradient**{: #BrushTypePathGradient } | `3` | A gradient that follows the shape of a path. |
| **BrushTypeLinearGradient**{: #BrushTypeLinearGradient } | `4` | A linear gradient. |
