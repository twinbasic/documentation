# GpImageType enumeration
{: .no_toc }

Says whether an image is a bitmap or a metafile.

| Member | Value | Description |
|:-------|:------|:------------|
| **ImageTypeUnknown**{: #ImageTypeUnknown } | `0` | The image is of an unknown type. |
| **ImageTypeBitmap**{: #ImageTypeBitmap } | `1` | The image is a bitmap. |
| **ImageTypeMetafile**{: #ImageTypeMetafile } | `2` | The image is a metafile. |
