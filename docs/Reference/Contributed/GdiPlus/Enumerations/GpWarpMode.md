# GpWarpMode enumeration
{: .no_toc }

Selects the kind of warp that **GraphicsPath.Warp** applies to a path.

| Member | Value | Description |
|:-------|:------|:------------|
| **WarpModePerspective**{: #WarpModePerspective } | `0` | A perspective warp. |
| **WarpModeBilinear**{: #WarpModeBilinear } | `1` | A bilinear warp. |
