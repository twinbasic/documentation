# FillStyleConstants enumeration
{: .no_toc }

Selects whether the shapes that [**VBGraphics**](../VBGraphics) draws are filled.

The enumeration is declared inside the **VBGraphics** class. Its members are used without a qualifier, or with the name of the enumeration. The names follow the VB6 constants of the same names.

| Member | Value | Description |
|:-------|:------|:------------|
| **vbFSSolid**{: #vbFSSolid } | `0` | A box drawn by **Line** and a circle or an ellipse drawn by **Circle** are filled with the **FillColor** of the object. |
| **vbFSTransparent**{: #vbFSTransparent } | `1` | Shapes are not filled. This is the default. |

## Used by

- [**VBGraphics**](../VBGraphics) class: [**FillStyle**](../VBGraphics#fillstyle)
