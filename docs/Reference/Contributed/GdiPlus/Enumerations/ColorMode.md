# ColorMode enumeration
{: .no_toc }

Names the two layouts of a colour value: 32 bits per colour or 64 bits per colour.

No public member takes or returns this enumeration. A [**Color**](../Types/Color) is always 32-bit ARGB.

| Member | Value | Description |
|:-------|:------|:------------|
| **ColorModeARGB32**{: #ColorModeARGB32 } | `0` | A colour is a 32-bit ARGB value, 8 bits for each of alpha, red, green and blue. |
| **ColorModeARGB64**{: #ColorModeARGB64 } | `1` | A colour is a 64-bit ARGB value, 16 bits for each of alpha, red, green and blue. |
