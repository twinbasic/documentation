# GpGenericFontFamily enumeration
{: .no_toc }

Names the three generic font families that GDI+ maps to an installed font.

No public member takes or returns this enumeration. [**FontFamily**](../FontFamily) has a member for each family: **GenericSerif**, **GenericSansSerif** and **GenericMonospace**.

| Member | Value | Description |
|:-------|:------|:------------|
| **GenericFontFamilySerif**{: #GenericFontFamilySerif } | `0` | A generic serif font family. |
| **GenericFontFamilySansSerif**{: #GenericFontFamilySansSerif } | `1` | A generic sans serif font family. |
| **GenericFontFamilyMonospace**{: #GenericFontFamilyMonospace } | `2` | A generic monospace font family. |
