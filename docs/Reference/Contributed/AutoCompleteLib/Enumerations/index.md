# AutoCompleteLib Enumerations
{: .no_toc }

The three public enumerations of the package, all declared inside the [**AutoComplete**](../AutoComplete) class. Their members can be written with or without the name of the enumeration, as in `AutoCompleteOptionAppend` or `AutoCompleteOptionConstants.AutoCompleteOptionAppend`.

- [AutoCompleteFileSystemOptionConstants](AutoCompleteFileSystemOptionConstants) -- which file-system objects the file-system source offers
- [AutoCompleteOptionConstants](AutoCompleteOptionConstants) -- how the completion behaves while the user types
- [AutoCompleteSourceConstants](AutoCompleteSourceConstants) -- where the suggestions come from
