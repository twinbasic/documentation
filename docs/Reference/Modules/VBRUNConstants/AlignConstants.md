# AlignConstants
{: .no_toc }

Values for the **Align** property of forms and controls — picture boxes, data controls, and toolbars — that anchor a control to one edge of its container.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbAlignNone**{: #vbAlignNone } | 0 | Size and location are set at design time or in code. |
| **vbAlignTop**{: #vbAlignTop } | 1 | Control is anchored to the top edge of the container. |
| **vbAlignBottom**{: #vbAlignBottom } | 2 | Control is anchored to the bottom edge of the container. |
| **vbAlignLeft**{: #vbAlignLeft } | 3 | Control is anchored to the left edge of the container. |
| **vbAlignRight**{: #vbAlignRight } | 4 | Control is anchored to the right edge of the container. |
