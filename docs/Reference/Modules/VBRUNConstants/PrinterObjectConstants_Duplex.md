# PrinterObjectConstants_Duplex
{: .no_toc }

Duplex-mode values for the **Printer.Duplex** property. Tagged **\[MustBeQualified\]**, so members must be referenced through the enum name (`PrinterObjectConstants_Duplex.vbPRDPSimplex`).

| Constant | Value | Description |
|----------|-------|-------------|
| **vbPRDPSimplex**{: #vbPRDPSimplex } | 1 | Print on one side only. |
| **vbPRDPHorizontal**{: #vbPRDPHorizontal } | 2 | Two-sided printing, with pages bound on the long edge (book style). |
| **vbPRDPVertical**{: #vbPRDPVertical } | 3 | Two-sided printing, with pages bound on the short edge (calendar style). |
