# MultiSelectConstants
{: .no_toc }

Multi-selection mode values for the **MultiSelect** property of a list-box control.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbMultiSelectNone**{: #vbMultiSelectNone } | 0 | Only one item can be selected at a time. |
| **vbMultiSelectSimple**{: #vbMultiSelectSimple } | 1 | Each click toggles the clicked item's selection. |
| **vbMultiSelectExtended**{: #vbMultiSelectExtended } | 2 | The user can select ranges with **Shift** + click and toggle individual items with **Ctrl** + click. |
