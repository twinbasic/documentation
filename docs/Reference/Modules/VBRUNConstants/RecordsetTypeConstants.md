# RecordsetTypeConstants
{: .no_toc }

Recordset-type values for the **RecordsetType** property of a Data control.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbRSTypeTable**{: #vbRSTypeTable } | 0 | A table-type recordset — direct read/write access to a single table. |
| **vbRSTypeDynaset**{: #vbRSTypeDynaset } | 1 | A dynaset-type recordset — an updatable, dynamic view of a query result. |
| **vbRSTypeSnapShot**{: #vbRSTypeSnapShot } | 2 | A snapshot-type recordset — a read-only fixed copy of a query result. |
