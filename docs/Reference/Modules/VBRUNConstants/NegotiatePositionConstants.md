# NegotiatePositionConstants
{: .no_toc }

Position values for the **NegotiatePosition** property of menu items, controlling where a menu appears when an OLE in-place active object negotiates the host's menu bar.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbNegotiatePositionNone**{: #vbNegotiatePositionNone } | 0 | The menu is hidden during in-place activation. |
| **vbNegotiatePositionLeft**{: #vbNegotiatePositionLeft } | 1 | The menu is placed in the left group of the negotiated menu bar. |
| **vbNegotiatePositionMiddle**{: #vbNegotiatePositionMiddle } | 2 | The menu is placed in the middle group. |
| **vbNegotiatePositionRight**{: #vbNegotiatePositionRight } | 3 | The menu is placed in the right group. |
