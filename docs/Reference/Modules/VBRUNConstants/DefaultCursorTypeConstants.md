# DefaultCursorTypeConstants
{: .no_toc }

Cursor-driver values for a Data control's connection, controlling whether the database client or the server manages the recordset cursor.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbUseDefaultCursor**{: #vbUseDefaultCursor } | 0 | Use the data source's default cursor driver. |
| **vbUseODBCCursor**{: #vbUseODBCCursor } | 1 | Use the client-side ODBC cursor library. |
| **vbUseServersideCursor**{: #vbUseServersideCursor } | 2 | Use a server-side cursor managed by the database engine. |
