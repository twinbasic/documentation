# DragOverConstants
{: .no_toc }

State values reported in the *State* argument of a control's **DragOver** event.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbEnter**{: #vbEnter } | 0 | The dragged source has just entered the target. |
| **vbLeave**{: #vbLeave } | 1 | The dragged source has just left the target. |
| **vbOver**{: #vbOver } | 2 | The dragged source is moving over the target. |
