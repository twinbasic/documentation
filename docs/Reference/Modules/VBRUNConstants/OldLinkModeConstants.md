# OldLinkModeConstants
{: .no_toc }

Legacy DDE link-mode values retained for compatibility with very early versions of Visual Basic. New code should use [**LinkModeConstants**](LinkModeConstants).

| Constant | Value | Description |
|----------|-------|-------------|
| **vbHot**{: #vbHot } | 1 | The control updates whenever the source data changes ("hot" link). |
| **vbServer**{: #vbServer } | 1 | The form acts as a DDE source. |
| **vbCold**{: #vbCold } | 2 | The control updates only when explicitly requested ("cold" link). |
