# LoadPictureSizeConstants
{: .no_toc }

Size selectors for the *vbLPSize* argument of **LoadPicture**, used when a source file (typically an icon) contains several sizes.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbLPSmall**{: #vbLPSmall } | 0 | Use the standard small system size (typically 16×16). |
| **vbLPLarge**{: #vbLPLarge } | 1 | Use the standard large system size (typically 32×32). |
| **vbLPSmallShell**{: #vbLPSmallShell } | 2 | Use the small shell size (the size used in Windows Explorer's small-icon view). |
| **vbLPLargeShell**{: #vbLPLargeShell } | 3 | Use the large shell size. |
| **vbLPCustom**{: #vbLPCustom } | 4 | Use a custom size supplied alongside the call. |
