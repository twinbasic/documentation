# OLEContainerActivateConstants
{: .no_toc }

Activation-trigger values for the **AutoActivate** property of an **OLE** container control.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbOLE_ActivateManual**{: #vbOLE_ActivateManual } | 0 | The embedded object is activated only when the **DoVerb** method is called. |
| **vbOLE_ActivateGetFocus**{: #vbOLE_ActivateGetFocus } | 1 | The object activates when the **OLE** container receives focus. |
| **vbOLE_ActivateDoubleclick**{: #vbOLE_ActivateDoubleclick } | 2 | The object activates when the user double-clicks it. |
| **vbOLE_ActivateAuto**{: #vbOLE_ActivateAuto } | 3 | The object activates automatically based on its registered defaults. |
