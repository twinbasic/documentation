# OLEContainerDisplayTypeConstants
{: .no_toc }

Display-style values for the **DisplayType** property of an **OLE** container control.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbOLE_DisplayContent**{: #vbOLE_DisplayContent } | 0 | The object's contents are displayed. |
| **vbOLE_DisplayIcon**{: #vbOLE_DisplayIcon } | 1 | The object is displayed as an icon. |
