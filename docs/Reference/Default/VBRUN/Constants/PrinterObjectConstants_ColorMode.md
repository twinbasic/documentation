# PrinterObjectConstants_ColorMode
{: .no_toc }

Colour-mode values for the **Printer.ColorMode** property. Tagged **\[MustBeQualified\]**, so members must be referenced through the enum name (`PrinterObjectConstants_ColorMode.vbPRCMColor`).

| Constant | Value | Description |
|----------|-------|-------------|
| **vbPRCMMonochrome**{: #vbPRCMMonochrome } | 1 | Print in monochrome. |
| **vbPRCMColor**{: #vbPRCMColor } | 2 | Print in colour. |
