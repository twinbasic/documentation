# ColorConstants
{: .no_toc }

Common named RGB colour values, suitable wherever a colour is supplied as a **Long** or **OLE_COLOR**. The numeric values follow the GDI byte order --- `&H00BBGGRR`.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbBlack**{: #vbBlack } | 0 | Black. |
| **vbRed**{: #vbRed } | 255 | Red. |
| **vbGreen**{: #vbGreen } | 65280 | Green. |
| **vbYellow**{: #vbYellow } | 65535 | Yellow. |
| **vbBlue**{: #vbBlue } | 16711680 | Blue. |
| **vbMagenta**{: #vbMagenta } | 16711935 | Magenta. |
| **vbCyan**{: #vbCyan } | 16776960 | Cyan. |
| **vbWhite**{: #vbWhite } | 16777215 | White. |
