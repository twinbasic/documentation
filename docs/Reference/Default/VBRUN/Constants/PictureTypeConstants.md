# PictureTypeConstants
{: .no_toc }

Subtype values reported by the **Type** property of an **stdole.IPictureDisp**.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbPicTypeNone**{: #vbPicTypeNone } | 0 | The picture is empty. |
| **vbPicTypeBitmap**{: #vbPicTypeBitmap } | 1 | A device-dependent or device-independent bitmap. |
| **vbPicTypeMetafile**{: #vbPicTypeMetafile } | 2 | A Windows metafile. |
| **vbPicTypeIcon**{: #vbPicTypeIcon } | 3 | An icon. |
| **vbPicTypeEMetafile**{: #vbPicTypeEMetafile } | 4 | An enhanced metafile. |
