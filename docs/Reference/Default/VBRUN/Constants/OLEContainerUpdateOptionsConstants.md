# OLEContainerUpdateOptionsConstants
{: .no_toc }

Update-mode values for the **UpdateOptions** property of an **OLE** container control, controlling how a linked object is kept in sync with its source.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbOLE_UpdateAutomatic**{: #vbOLE_UpdateAutomatic } | 0 | The object is updated whenever the source data changes. |
| **vbOLE_UpdateFrozen**{: #vbOLE_UpdateFrozen } | 1 | Updates are paused. |
| **vbOLE_UpdateManual**{: #vbOLE_UpdateManual } | 2 | The object is updated only when **Update** is called. |
