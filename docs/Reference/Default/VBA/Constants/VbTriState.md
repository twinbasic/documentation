# VbTriState
{: .no_toc }

Three-state values used in place of **Boolean** arguments where a "use default" option must remain selectable. Common in formatting functions such as [**FormatNumber**](../Strings/FormatNumber), [**FormatPercent**](../Strings/FormatPercent), and [**FormatCurrency**](../Strings/FormatCurrency).

| Constant | Value | Description |
|----------|-------|-------------|
| **vbTrue**{: #vbTrue } | -1 | True. |
| **vbFalse**{: #vbFalse } | 0 | False. |
| **vbUseDefault**{: #vbUseDefault } | -2 | Use the system default setting. |
