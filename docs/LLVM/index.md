# LLVM

twinBASIC can compile a project with LLVM, an optimizing compiler back end built into the IDE, to make the program faster and smaller.

## Topics

- [Getting Started with LLVM](Getting-Started) -- what LLVM does, turning it on for a project or for a single procedure, the IDE options that control it, and its current limitations.
