## Global Search

This AddIn is supplied with the twinBASIC IDE.

Latest Release
: v1.0.0.0

Developer
: twinBASIC

The global search add in will contain a [Toolbar](../Project/Toolbar) item.

![A single toolbar button labelled Global Search.](Images/Toolbar_GlobalSearch.png)

![The Global Search tool window before a search: an empty search box with a magnifier icon, and four clear checkboxes labelled In packages, Match case, Whole word and Exclude comments.](Images/GlobalSearch.png)

Options

- In packages
- Match case
- Whole word
- Exclude comments

Type a search term i.e. Button1 into the text field and a list of matches will be returned.

![The Global Search window after searching for Button1 with In packages ticked. Each result is a card giving the file name, its size in bytes, its path, a match count and the matching line of code with Button1 highlighted, followed by its line and column position. Constants.twin reports one match and MainModule.twin seventeen.](Images/GlobalSearch_2.png)
