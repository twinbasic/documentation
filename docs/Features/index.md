# Features

This section documents all the features and enhancements that twinBASIC brings compared to VBx and earlier BASIC dialects. Features are organized into the following categories:

- [Attributes](Features/Attributes) - Attribute syntax and annotations
- [Language Syntax](Features/Syntax) - Language enhancements including new data types, generics, inheritance, and more
- [Project Configuration](Features/Project) - Project types and compiler options
- [Standard Library](Features/Standard-Library) - Enhanced standard library with Unicode support and new functions
- [GUI Components](Features/GUI-Components) - Modern forms, controls, and UI components
- [Advanced Features](Features/Advanced) - Advanced features like multithreading, assembly, and static linking
- [Compiler and IDE Features](Features/Compiler-IDE) - Development tools and IDE enhancements
- [64bit Compilation](Features/64bit) - Native 64-bit compilation support
