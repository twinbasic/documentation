{%- comment -%} Collects all pages that match the entry's page selectors and appends them (in order) to the outer-scope `collected` variable. Caller is responsible for initialising `collected` to an empty array (`{%- assign collected = "" | split: "" -%}`) before the include and for any subsequent sorting / filtering of the result. Inputs (via `include.entry = ...`): entry -- the book.yml entry (front_matter item, part, or chapter). May carry any combination of: page -- single URL prefix pages -- list of URL prefixes nav_page -- single nav_path prefix nav_pages -- list of nav_path prefixes no_descent -- when truthy, every selector matches by exact equality instead of the default `contains` semantics `page:` is shorthand for a single-element `pages:` list, and `nav_page:` is shorthand for a single-element `nav_pages:` list; both can coexist with their plural counterparts on the same entry (the union is appended). `landing_page:` and `foreword_page:` are separate concepts and aren't handled here -- the caller emits them with their own semantics (landing-first, foreword-special-styling). The hack `value | split: "<<>>"` wraps a single string in a one-element array; the separator is chosen to not appear in any real URL or nav_path so `split` doesn't actually split. {%- endcomment -%} {%- assign url_specs = "" | split: "" -%} {%- if include.entry.page -%} {%- assign url_specs_one = include.entry.page | split: "<<>>" -%} {%- assign url_specs = url_specs | concat: url_specs_one -%} {%- endif -%} {%- if include.entry.pages -%} {%- assign url_specs = url_specs | concat: include.entry.pages -%} {%- endif -%} {%- for prefix in url_specs -%} {%- if include.entry.no_descent -%} {%- assign matched = site.pages | where: "url", prefix -%} {%- else -%} {%- assign matched = site.pages | where_exp: "p", "p.url contains prefix" -%} {%- endif -%} {%- assign collected = collected | concat: matched -%} {%- endfor -%} {%- assign nav_specs = "" | split: "" -%} {%- if include.entry.nav_page -%} {%- assign nav_specs_one = include.entry.nav_page | split: "<<>>" -%} {%- assign nav_specs = nav_specs | concat: nav_specs_one -%} {%- endif -%} {%- if include.entry.nav_pages -%} {%- assign nav_specs = nav_specs | concat: include.entry.nav_pages -%} {%- endif -%} {%- for np in nav_specs -%} {%- if include.entry.no_descent -%} {%- assign matched = site.pages | where: "nav_path", np -%} {%- else -%} {%- assign matched = site.pages | where_exp: "p", "p.nav_path contains np" -%} {%- endif -%} {%- assign collected = collected | concat: matched -%} {%- endfor -%}
