{%- comment -%} Hand-rolled replacement for jekyll-seo-tag's `seo` tag. Produces byte-identical output to jekyll-seo-tag v2.8.0 for this site's configuration (verified by `diff -rq _site/` against the pre-precompute baseline). All per-page derivations -- title, full title, canonical URL, homepage flag -- and the site-level title + logo URL are precomputed once per build in `_plugins/seo-precompute.rb` at `:site, :pre_render`. This template just reads them back as `page._seo_*` (PageDrop falls back to `page.data`) and `site._seo_*` (SiteDrop falls back to `site.config`). See the plugin's header comment for the full rationale: the `markdownify | strip_html | normalize_whitespace | escape_once` pipeline that used to live here ran ~1,674 times per build (`page.title` + `site.title` per render * ~837 pages), dominating ruby-prof's `Liquid::Strainer#invoke` breakdown. 834 of the 836 page titles on this site are plain ASCII strings where the pipeline reduces to a straight `escape_once(title)`. {%- endcomment -%} {{ page._seo_full_title }}
