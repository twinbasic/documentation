{%- comment -%} Shadow of just-the-docs's _includes/components/nav/links.html. The upstream version invokes `nav/children.html` (which queries `nav_parenthood | where: "name", node.title | map: items | first`, applies the `grand_parent` / `ancestor` disambiguation, and calls `nav/sorted.html` to bucket-sort the survivors) for every nav node, then recurses with parameter-bound `include`. The overhead accounts for ~3.5 s of RENDER time on this site (~67 invocations of links.html + ~815 invocations of children.html during the single `include_cached` site_nav fill). This shadow consumes the precomputed nav tree on `site.nav_tree`, built by `_plugins/nav-tree-precompute.rb`. Each node is a Hash with `title`, `url`, and `children` -- the `children` array is already filtered (nav_exclude, grand_parent disambiguation) and sorted (nav_order, title precedence, with `child_nav_order` reversal applied). The template just iterates the children; no `nav_parenthood`, no `where`, no `group_by`. Include as: {%- include components/nav/links.html pages=node_array ancestors=title_array -%} Each entry in `pages` must be a Hash with keys `title`, `url`, `children`. `ancestors` is the chain of titles of ancestors of the current scope (empty array at top level). The title-based ancestor check is preserved as a safety net for pages with the same title as one of their ancestors: such pages render as an infinity link without recursion, matching the upstream visual. The companion `nav_error_report` capture from the upstream is dropped; see the shadow `site_nav.html` for the rationale. The `include.all` parameter the upstream supports is dropped: the precomputed tree has `nav_exclude` pages filtered out, so the "render all pages" variant is not available. The only remaining caller on this site is `sidebar.html` (via `include_cached site_nav.html`), which never passes `all=true`. If a future change needs the all-pages variant, the precomputed tree would need a parallel `nav_tree_all` field (or this shadow would need to fall back to upstream behaviour). {%- endcomment -%}
