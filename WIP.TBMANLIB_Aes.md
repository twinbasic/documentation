# TBMANLIB_Aes --- working notes

The contributed TBMANLIB_Aes package, documented at `docs/Reference/Contributed/TBMANLIB_Aes/`. This
file holds what its section decided and what is known about the package beyond its pages; the
rules for every contributed package are in [WIP.Contributed.md](WIP.Contributed.md).

**Listed under Experimental Packages** (owner): TBMANLIB_Aes runs other cipher modes than the ones named (its default CBC is ECB) and fails the NIST test vectors.
