# xCalendar --- working notes

The contributed xCalendar package, documented at `docs/Reference/Contributed/xCalendar/`. This file
holds what its section decided and what is known about the package beyond its pages; the rules for
every contributed package are in [WIP.Contributed.md](WIP.Contributed.md).

xCalendar (one control) is one page (owner), so `analyze` in audit mode lists its classes and members as undocumented.

What xCalendar's page says it does at run time comes from `test/package-tests/xCalendar/probe/`, which runs the control on a form in a built exe.
